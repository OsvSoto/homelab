# Homelab

Proyecto de aprendizaje: Linux, servidores, cloud y seguridad por fases.

- Anfitrion: Ubuntu (Vivobook14), notebook con dualboot Windows11 - Ubuntu
- Virtualización: KVM/libvirt
- Fase actual: 0 (base Linux)

## Estructura

- fases/ guias y objetivos de cada fase
- runbooks/ procedimientos: como restaurar, como reparar, como renovar
- notas/ bitacora: que hice, que se rompio, como lo arregle
